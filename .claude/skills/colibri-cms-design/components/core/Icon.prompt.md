Icône au trait Lucide, en currentColor, pour accompagner un libellé — jamais seule.

```jsx
<Icon name="upload-cloud" />
<Icon name="trash-2" size={16} />
```

- `size` : 20 px dans l'interface, 16 px dans un badge ou une ligne de tableau.
- `strokeWidth` reste à 1,5 : c'est l'épaisseur retenue pour la marque.
- Nécessite le script Lucide UMD (`https://unpkg.com/lucide@latest`) sur la page.
