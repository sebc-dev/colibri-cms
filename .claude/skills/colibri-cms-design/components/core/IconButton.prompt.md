Action secondaire réduite à une icône, dans une barre d'outils, une ligne de tableau ou une vignette.

```jsx
<IconButton icon="pencil" label="Modifier le texte" />
<IconButton icon="trash-2" label="Supprimer la photo" variant="danger" />
```

Jamais pour l'action principale d'un écran : une cliente ne devine pas une icône seule.
