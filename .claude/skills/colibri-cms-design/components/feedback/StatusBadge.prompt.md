État d'un contenu ou d'une demande, en pastille `radius-pill`, style `label`.

```jsx
<StatusBadge state="publie" />
<StatusBadge state="modifie" />
<StatusBadge state="devis-envoye" />
```

États de publication : `publie`, `modifie` (pastille gorge), `brouillon`, `publication`, `echec`.
États de devis : `sans-suite`, `devis-envoye`, `commande`.
